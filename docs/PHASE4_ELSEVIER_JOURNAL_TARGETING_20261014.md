### Nonnegotiable before-submission gates

1. Adopt correct **connectivity database-label agreement** endpoint, not independent authenticated molecule identification.
2. Preprint-ready reproducibility ledgers and software deterministic checksum proofs, including historical 609 now SPENT and historical 466 previously exposed, disclose 69/609 prior chemical overlap.
3. Same-case HGB vs margin/cosine error curves with exact accepted numerators/denominators; disclose nonuniform HGB advantage, developmental 12-feature logistic near-tie, no 5/10 risk certification.
4. Separate analytic limitations (in-library only, no v2 RI/conformal, no source-independent acquisition, no out-of-library) in title/abstract/figures.
5. Relate directly to 1994 Stein, 2015 Kim/Zhang, 2025 McGlynn, 2025 probabilistic EI scores, 2026 EI out-of-library and EI-isomer advances, FastEI, LLM4MS; no unsupported best/first claims.
6. Demonstrate software **utility**, not only code parity: error/warning/fault injection checks on clearly defined predeclared input scenarios, reproducible candidate output and data source licensing. These are computational; they are not a substitute for laboratory truth or cross-tool matched-performance superiority.
